# 像素工坊 · Minecraft 皮肤编辑器

一个轻量的 Minecraft 皮肤编辑器。下载本仓库后，直接用浏览器打开 `index.html` 即可使用，无需安装依赖。

- 导入、导出 64 × 64 PNG 皮肤
- 选择经典（4 像素）或纤细（3 像素）手臂
- 按部位、方向和基础层 / 外层逐像素编辑
- 画笔、橡皮、填充、取色，以及撤销和重做
- 光谱、RGB / HSV 数值、HEX 和蜂窝色板选色
- 在支持屏幕取色的浏览器中从屏幕取色；不支持时可从画布取色
- 正面、背面和侧面的平面预览

皮肤图像在浏览器本地处理，编辑内容会保存在当前浏览器的本地存储中。清除浏览器数据或更换浏览器可能导致本地保存的内容丢失；建议及时导出 PNG。

导入已有皮肤时请选择匹配的手臂模型；切换模型不会自动转换手臂纹理。目前只支持导入 64 × 64 PNG。

本项目为独立制作的工具，与 Mojang Studios 或 Minecraft 官方无关联。
